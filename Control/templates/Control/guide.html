1. Overview

LeadPlus-360 is the internal operating system for our IT company (software & web development, digital marketing, SEO, ad-video production). It unifies four domains:

■

CRM

Leads, pipeline, activities, follow-ups, quick-lead capture, exports.

☺

HR

Employee directory, onboarding workflows, documents, task checklists.

●

Attendance

AI face recognition, geo-fencing, punch in/out, monthly reports.

★

Performance

KPI scoring, BDE targets, leaderboards, PIPs, TV wall display.

3. Getting Started

3.1 First login

  1. Open /login/ — use credentials provided by your admin.
  2. On first visit you land on Home — widgets appear based on your role.
  3. Open Profile (top-right avatar) → Change password immediately.

3.2 Sidebar navigation

The left sidebar shows only sections your role permits. Collapse on mobile with the ☰ button.

4. Attendance (Face + Geo)

4.1 Face enrolment (one-time)

  1. Open Attendance from sidebar.
  2. Click Enrol face — allow camera permission.
  3. Center your face in the oval; the system captures 15 frames.
  4. Success toast appears; you can now punch.

4.2 Punch in / out

  1. Open Attendance page.
  2. Click Punch in (morning) or Punch out (evening).
  3. Camera snapshots are taken for verification.
  4. GPS is checked against allowed office radius.

Status badges: Present Late Outside radius Missed

4.3 HR: Attendance today & Monthly report

  • Attendance today — live list of present/late/absent with filter by department.
  • Monthly report — calendar grid, export CSV, filter by employee/date range.
  • Reset face — if an employee changes appearance, HR can trigger re-enrolment.

4.4 Office locations (geo-fencing)

HR/Admin define offices: name, address, latitude, longitude, radius (metres). Punches outside radius are flagged Outside radius.

5. CRM — Leads & Pipeline

5.1 Lead list

Filters: stage, source, assigned, date range, search by name/company/email/phone. Columns: name, company, stage, value, next follow-up, owner.

5.2 Create / edit lead

Fields: name, company, email, phone, source, stage, value, assigned to, tags, notes. Quick lead (⚡) captures minimal fields for speed.

5.3 Pipeline view

Kanban columns: New → Contacted → Qualified → Proposal → Negotiation → Won / Lost. Drag & drop to change stage; inline activity log on card click.

5.4 Activities & follow-ups

Log call, meeting, email, WhatsApp, note. Set Next follow-up date — appears in Follow-ups list and on Home dashboard.

5.5 Export leads

CSV export respects current filters and user's lead scope.

6. Follow-ups & Tasks

  • Follow-ups — auto-generated from lead next-follow-up dates. Mark complete, reschedule, or convert to task.
  • Tasks — standalone to-dos assignable to any CRM user. Status: To-do / In progress / Done.
  • Add task — quick create from sidebar or lead detail.

7. Performance & KPIs

7.1 Leaderboard

Monthly score = Σ (KPI value × weight). Shown for current month; filter by role/department. Top 3 appear on manager Home.

7.2 My performance

Shows your score, rank, each KPI with actual vs target, trend sparkline.

7.3 KPI setup (Admin/HR)

Define KPIs per role: name, unit, target, weight, formula (manual entry or auto from CRM/attendance). Weights must sum to 100.

8. BDE Targets & Appraisals

8.1 BDE dashboard

Business Development Executive targets: monthly revenue, leads created, conversion rate, activities. Progress bars update in real time.

8.2 Calendar view

Heatmap of daily activity counts; click a day to see logs.

8.3 Appraisals

Quarterly/annual review cycles: self-assessment → manager review → HR finalise. PDF export for records.

8.4 Improvement plans (PIP)

Create structured plan with milestones, check-in dates, owner. Track status: Active / Completed / Closed.

9. HR — Employees & Onboarding

9.1 Employee directory

List with filters: status, department, role. Click for detail: profile, documents, onboarding checklist, performance history.

9.2 Add employee (creates login + onboarding)

  1. Employees → New — fill personal, professional, role, department, manager.
  2. System creates Django user, sends welcome email with temp password.
  3. Onboarding checklist auto-generated from Workflows matching role/department.

9.3 Onboarding board

Kanban: Pending → In progress → Submitted → Approved. HR/manager approve steps marked needs approval.

9.4 Workflows (templates)

Define checklist templates per role/department. Steps: title, description, assignee (self/HR/manager), approval required, order. Matching priority: role → department → default.

9.5 Documents

Upload contracts, ID proofs, offer letters per employee. Categories: contract, id, certificate, other.

10. TV Displays (Live Leaderboard)

  1. Super Admin → TV displays → New.
  2. Name it (e.g. "Main floor TV"), choose rotation interval (default 10s).
  3. System generates a token URL: /tv//.
  4. Open that URL on the office TV browser (full-screen, kiosk mode).
  5. It cycles through employees showing name, role, photo, score, rank, top KPIs.

Security: Anyone with the link can view — keep it on internal network only.

11. Super Admin — Configuration

11.1 Control Center

Overview: user count, active roles, offices, quick actions (toggle active, set role, reset password).

11.2 Roles & access

Create/edit roles, set capabilities, level (seniority), privileged flag. Assign permissions from Django auth.

11.3 Onboarding workflows

Build reusable checklists. See §9.4.

11.4 KPI setup

Define measurable KPIs per role with weights. See §7.3.

11.5 TV displays

Manage tokens, rotation speed, which roles/departments to show. See §10.

11.6 Django admin

Raw data access at /admin/ — use sparingly.

12. Typical First-Day Setup (Super Admin)

  1. Office locations — add lat/lng/radius for each office (Attendance → Office locations).
  2. Review roles — verify capabilities match org chart (Control Center → Roles).
  3. Edit onboarding workflows — create checklists per role/dept (HR → Workflows).
  4. Set KPIs — define targets & weights per role (Admin → KPI setup).
  5. Add employees — HR → Employees → New (auto-creates login + onboarding).
  6. Face enrolment drive — ask all staff to open Attendance and enrol.
  7. Create TV display — generate token, open on office TV.

13. FAQ & Troubleshooting

Camera/location permission denied?
Browser settings → Site permissions → Allow camera & location for this origin. Refresh page.
Punch flagged "Outside radius"?
Check office coordinates in Admin → Office locations. Increase radius or correct GPS.
Face recognition fails?
Good lighting, face centred, no mask/glasses. HR can "Reset face" for re-enrolment.
Lead not visible?
Scope is role-based: Executives see own, Team Leads see team, Managers+ see all.
Performance score not updating?
KPIs recalculate on data entry. Force recalc: Admin → BDE → Recalculate.
TV display shows "Unauthorized"?
Token expired or revoked. Generate new token in TV displays.
Forgot password?
Admin can reset in Control Center; or use "Forgot password" on login (if email configured).
